Short answer

Hushed Sanctum is the separate cleanse dungeon you enter by selecting Cleanse Beacon at the Citadel Annex Beacon inside the Faded Citadel. Sources report a multi-room sequence that ends when you interact with a corrupted crystal core; the game then shows "Beacon Cleansed."

[IMAGE: Citadel Annex Beacon area]

Location and how to enter

- Hushed Sanctum is not Ashen Sanctum. It is the distinct cleanse instance triggered from the Citadel Annex Beacon inside the Faded Citadel.
- Route anchor: reach the Citadel Annex Beacon via the Faded Citadel interior (Gate of Infinity → Ashen Sanctum approach → Citadel Annex). For broader route context and reaching the Annex Beacon, see the Faded Citadel walkthrough: /mortal-shell-ii/faded-citadel/.
- At the Citadel Annex Beacon, choose Cleanse Beacon to load Hushed Sanctum (this is the reported entry method).

Reported cleanse sequence (secondary-source outline)

Sources (AllThingsHow and local reporting) list the following sequence when you pick Cleanse Beacon at Citadel Annex. This is a reported route — use it as a checklist while playing:

1. Narrow bridge with a ranged caster
2. Tunnel with melee enemies and spiders
3. Stairs with a teleporting lightning caster
4. Large pillared spider room
5. Platforming / drop into a circular arena
6. A red rift to a high ledge (mage + chest)
7. Interact with the corrupted crystal core to complete the cleanse

When completion registers you should see a "Beacon Cleansed" message. Reward is reported as Stillblade's Stone (a Tarstone).

[IMAGE: Hushed Sanctum bridge and narrow tunnel]

Stillblade's Stone (reported)

- Multiple sources report Stillblade's Stone as the reward for the Citadel Annex cleanse. Stillblade's Stone is catalogued as a Tarstone; for the item entry and related Tarstones, see: /mortal-shell-ii/tarstones.

How to finish the cleanse — the corrupted core requirement

- The cleanse does not appear to complete simply by reaching a chest or leaving the instance. Local coverage specifically reports that taking the chest and leaving without interacting with the corrupted crystal core does not register the Beacon as cleansed.
- You must interact with the corrupted crystal core inside Hushed Sanctum. The core interaction is the final step that triggers the "Beacon Cleansed" confirmation.

[IMAGE: corrupted crystal core interaction area]

Why a Beacon might be stuck / troubleshooting

If the Citadel Annex Beacon does not mark as cleansed after you run Hushed Sanctum, do the following checks in order:

1. Confirm you interacted with the corrupted crystal core (not just looted any nearby chest).
2. Rest at the Citadel Annex bonfire and attempt Cleanse Beacon again to reload the sequence.
3. Cross-check the Beacons & fast travel documentation for general Beacon behavior and fast-travel state: /mortal-shell-ii/beacons-fast-travel/.
4. If you are having trouble due to specific enemies (for example Isaac-related mechanics or blue-flame damage), consult the Isaac page for combat guidance: /mortal-shell-ii/isaac-the-scholar-prince/.

Notes and boundaries

- The cleanse sequence above is reported by secondary sources (see Sources). Do not assume platform-specific fixes or additional steps beyond the corrupted core interaction unless confirmed by official patch notes.
- If you still see issues after verifying the core interaction and retesting, re-check the Citadel Annex rest and Beacons documentation before pursuing platform- or bug-specific troubleshooting.

Common mistakes

- Leaving after looting the chest: taking the chest without interacting with the corrupted crystal core does not complete the cleanse.
- Confusing Ashen Sanctum with Hushed Sanctum: Hushed Sanctum is the Citadel Annex cleanse instance and is separate from Ashen Sanctum.
- Assuming a different trigger: the reported final trigger is the corrupted crystal core interaction — ensure you did that step.
