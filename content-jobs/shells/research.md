## Editorial decision

The page should answer “all Shells / best Shells” with a corrected roster model:

- **Nine Shells total** in launch coverage.
- **Harros** is the prologue-only Shell and is lost at the end of the prologue.
- **Eight permanent Shells:** Tiel, Proxima, Gragu, Eredrim, Smert, Lazlo, Sariel, and Genessa/Sester Genessa.
- Every permanent Shell requires the body/encounter interaction plus its first Memory or route-specific Memory completion before it is treated as permanently unlocked.
- Shell Bonding uses Glimpses, while Balance Patch 1 moved Shell-map reveals to Gloom and refunded eligible pre-patch Glimpse spending.
- Use-case guidance is allowed where supported; a universal S/A/B combat tier list is not supported by the current evidence set.

The page uses region and landmark route anchors, not invented coordinates. It keeps the Censer/Chalice naming conflict and route-direction conflicts visible.

## Unlock model, Memories, and Bonding

Cross-source stable claims:

1. Finding a body is not always the whole unlock.
2. Interact with the remains or route-specific Shell prompt.
3. Complete the first Memory / route-specific Memory sequence.
4. The permanent Shell becomes available after the sequence.
5. Spend Glimpses on Bonding to open higher perk tiers.
6. The standard Bonding interaction is at the Shellkeeper in Marrow Keep; GameSpot/AllThings.How describe Genessa as a dialogue-based exception at Genessa.
7. Shell-specific abilities/weapons are not the same as shared equipment. GamesRadar+ says Seals, Tarstones, and other items apply across Shells; local pages do not validate a full cross-Shell build matrix.

The page should not imply that “defeat the boss” alone unlocks every Shell. Sariel specifically requires the post-fight Unknown Shell/Memory step; Smert has The Convert/Hierarch sequence; Genessa has the return handoff and Memory.

## Progression timing

- **Prologue:** Harros is temporary and is lost at the end.
- **Immediately after prologue / early Fainweald:** Tiel and Proxima are the clearest early permanent options. GamesRadar+ says their locations are revealed after the prologue; local Proxima evidence supports a post-prologue route without a shown weapon/boss/key/Ova/Mether's Breath requirement. The local Tiel page should remain the exact route owner for Tiel.
- **Fainweald mid-route:** Gragu needs eastern access and the Heart of Vatra; Eredrim is behind the Citadel of Penance/Warden; Smert is behind the Prophet's Rest ritual and The Convert/Hierarch. Do not turn route access into a fixed Ova number.
- **Later Mammon:** Lazlo is boss/crypt gated by Vellen; Sariel is a multi-stage Chamber of Becoming route; Genessa is an indirect Sester Secundus → return handoff and is not an ordinary corpse pickup.

## Practical use cases and build boundary

Supported enough to publish:

- **Tiel:** mobile/evasive/Shadow-focused identity from the local route page; GamesRadar+ recommends him for early-mid game and calls him the better early option. Phrase as a practical starting recommendation, not objective dominance.
- **Proxima:** local transcript/UI supports lightning-lance pull utility and a transcript-stated damage-mitigation observation. Since this is single-walkthrough evidence, avoid presenting the numerical mitigation as a verified global stat.
- **Smert:** local page supports a Miracle/time-control-oriented identity. No full Miracle tree or stat comparison.
- **Eredrim:** GamesRadar+ places him as a mid-late game recommendation, but does not supply enough validated details for a complete build table. Keep recommendation at route timing/use case level.
- **Genessa:** route-specific Bonding interaction via dialogue is supported by independent guides; do not infer a combat tier from unlock complexity.

Not supported enough to publish as fact:

- universal S/A/B tier ordering;
- complete HP/damage/defense/stat table for all eight permanent Shells;
- complete ability or perk tree for every Shell;
- exact weapon/Shell pairings as “best” without controlled test conditions;
- pre-patch/beta combat rankings presented as current;
- a fixed total Glimpse cost or a universal optimal spending order unless a current primary in-game source is available.

## Missables and uncertainty register

1. **Harros:** strongest missable claim. Multiple current guides say he is lost permanently at the end of the prologue. He is not part of the eight permanent Shell collection.
2. **Tiel/Proxima bearings:** local and independent guides use slightly different compass phrasing. Preserve the named landmarks; do not invent map coordinates.
3. **Gragu access:** GameSpot reports an “around five extra Ova” route gate for One-Legged Wolf/Mether's Breath, while the local Gragu guide intentionally does not support a fixed Ova count. Publish “requires wider corruption/travel access” and link the broader progression guide instead of choosing a number.
4. **Genessa item name:** Censer vs Chalice appears across current guides and is already preserved in the local Sester Genessa page. Do not silently normalize it.
5. **Genessa decision:** GameSpot and AllThings.How say an accept/decline choice near the end of Genessa's Memory does not appear to create divergent Shell access, but this is not a complete ending/quest audit. Say “current guides report no different Shell unlock outcome” if mentioned.
6. **Lazlo:** no local standalone route page exists. Keep the hub entry at Mammon/High Lord's Courtyard/Vellen/crypt level and do not claim detailed route coordinates.
7. **Sariel:** local page supports four markers, post-fight Unknown Shell, and three reward separation; Destructoid explicitly leaves Sariel unfinished. Use local + GameSpot/AllThings.How.

## Patch notes relevant to Shell planning

Local `balance-patch-1.md` and GamesRadar+ agree on the practical Shell-specific change:

- Shell-map reveals moved from **Glimpses to Gloom**.
- Glimpses previously spent on those map reveals are refunded at the Shell Keeper's alcove in Blackmarrow.

Local page adds current rollout uncertainty: PC first, PS5 reported as received, Xbox availability unconfirmed in the page's evidence. The Shells hub should mention the resource change without claiming every platform has identical timing unless verified again.

The patch also changes enemy/weapon/Tarstone/economy balance, so old beta or pre-patch tier lists should not be repeated as current. No API call or provider call was used for this research.
