Short answer
Mortal Shell II does not have a traditional Easy/Normal/Hard menu. The closest built-in “easier” option is the Slayer Seal — an optional, in-world modifier whose Gloomslayer tools make Break/Riposte play more forgiving and restore some Health and Resolve on qualifying ripostes. Equipping the Slayer Seal on a save will lock achievements on that save (picking it up does not automatically trigger the lock). If you want to try a more forgiving run but keep achievements intact, use a separate save before equipping.

How to get and use the Slayer Seal (exact route)
1. Reach Marrow Keep after the Prologue.
2. From the Keep interior, follow the existing route toward Merrick and the outdoor ledge (use the current-page route visuals).
3. Pick up the Slayer Seal from the stone throne.
   [IMAGE: Slayer Seal pickup on stone throne in Marrow Keep route]
4. Before switching/equipping the Seal, decide whether achievement progress on that save matters to you. The verified evidence says equipping/switching the Seal locks achievements on that save; picking it up is not the same trigger.
5. If you want a more forgiving combat run, equip the Seal. If achievements matter, load or create a separate save and equip it there.

Mechanics (what the Slayer Seal does — as verified)
- Gloomslayer tools: make Break / Riposte play more forgiving and restore some Health and Resolve on qualifying ripostes.
- The Seal is not described in the verified notes as reducing enemy damage; treat its benefits as improved riposte/recovery tools rather than a flat damage-scaling Easy Mode.
- Equipping the Seal (not just picking it up) is the action tied to the achievement lock.

Practical recommendations
- If you’re learning routes or struggling with bosses/repeats, the Seal’s extra recovery and forgiving ripostes remain useful even after Balance Patch 1 changed enemy baselines. Balance Patch 1 restored beta HP values for beta enemies broadly and lowered some named bosses/enemies, but it did not add a conventional difficulty menu (Cold Symmetry patch notes).
- If you plan to chase achievement/Trophy completion, make a separate save before equipping the Seal so you can switch back for achievement runs. The current-page / AMA evidence explicitly recommends this.
- If equipping from a Beacon menu previously caused a UI lock for you, update to Hotfix 2.0; that specific Beacon-menu UI lock issue is officially fixed (XBIGY release notes). See /mortal-shell-ii/crashing-pc/ for the Hotfix 2.0 Beacon-menu UI-lock note.

Night Mode and future changes
- Night Mode remains the separate, harder optional world state already covered on the current page. Do not treat Night Mode as a slider or as the same thing as the Slayer Seal. Official notes mention future Night Mode work but include no unreleased mechanic details; do not speculate. See /mortal-shell-ii/gloombound-flame/ for the current Night Mode route.

Common mistakes
- Equipping vs. picking up: many players assume picking up the Seal locks achievements. The verified evidence says equipping/switching the Seal on a save is what locks achievements; picking it up is not the same trigger.
- Calling the Seal an “official Easy Mode” menu option: community shorthand may say “easy mode,” but there is no standard Easy/Normal/Hard menu—only the in-world Slayer Seal modifier.
- Assuming Patch 1 made everything easier: Balance Patch 1 restored beta HP values broadly and reduced some named enemies/bosses; it did not uniformly make every enemy or boss easier and did not replace the Seal’s usefulness for recovery/riposte.
- Forgetting to use a separate save if you care about achievements.
- Not updating to Hotfix 2.0 if you experienced a Beacon-menu UI lock when equipping from a Beacon; that issue is listed as fixed.

What happens next (after you equip the Seal)
- Achievements on that save are locked once you switch/equip the Slayer Seal (verified current-page / AMA evidence).
- You will gain the Seal’s riposte and recovery benefits while playing that save.
- Balance Patch 1’s baseline changes remain in effect; they do not remove the practical value of the Seal for players who want stronger recovery or more forgiving ripostes. (See Cold Symmetry’s Balance Patch 1 notes.)
- Night Mode remains a separate harder option and is not superseded by the Slayer Seal. Official notes mention further Night Mode work but provide no details; there is no confirmed future change to make Night Mode the same as a difficulty menu.
