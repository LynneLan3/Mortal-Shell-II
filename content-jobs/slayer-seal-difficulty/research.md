# Target intent

Reframe the existing `/mortal-shell-ii/slayer-seal-difficulty/` page around “Does Mortal Shell 2 have Easy Mode?” while preserving the current Slayer Seal mechanics. Do not create an Easy Mode page or speculate about unreleased Night Mode changes.

# Confirmed facts

- Mortal Shell II has no traditional Easy / Normal / Hard menu in the current guide evidence.
- The Slayer Seal is the optional easier-combat modifier: its Gloomslayer tools make Break / Riposte play more forgiving and restore some Health and Resolve on qualifying ripostes. It does not need to be described as lower enemy damage.
- The Seal is found after reaching Marrow Keep, at the current page's stone-throne route; preserve the existing route and image provenance.
- The existing verified current-page / AMA evidence says switching to or equipping the Slayer Seal locks achievements on that save. Picking it up is not the same trigger. Recommend a separate save for an achievement-focused player who wants to try it.
- Balance Patch 1 changed the baseline by restoring beta HP values for beta enemies as a broad direction and lowering several named boss/enemy values; it did not add a conventional difficulty menu.
- Night Mode is the harder optional world state already covered by the page. The official patch notes mention future Night Mode work but give no unreleased mechanic details; do not speculate.

# Route / procedure

1. Reach Marrow Keep after the Prologue.
2. Follow the existing route from the Keep interior toward Merrick and the outdoor ledge.
3. Pick up the Slayer Seal from the stone throne.
4. Before switching / equipping it, decide whether achievement progress matters on that save.
5. If the goal is a more forgiving combat run, equip it; if achievements matter, use a separate save and keep the warning visible.
