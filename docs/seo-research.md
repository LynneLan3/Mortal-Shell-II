# Mortal Shell II SEO research

Research date: 2026-08-11

## Confirmed identity and facts

- **Developer / publisher:** Cold Symmetry / Playstack.
- **Release:** August 20, 2026 worldwide on PC via Steam, PlayStation 5, and Xbox Series X|S.
- **Game identity:** a standalone sequel action-RPG; official copy emphasizes high-stakes combat, possessable warrior Shells, deeper weapon upgrades, and an interconnected open world.
- **Single-player status:** current Steam and console store listings identify single-player features. No multiplayer guide is published because additional multiplayer modes are not officially confirmed.
- **PC requirements:** Steam currently publishes a minimum table including Windows 10/11, 16 GB RAM, DirectX 12, 70 GB storage, and an SSD requirement. A filled recommended table is not published in the reviewed listing, so no values are invented.

## Intentionally omitted

No full Shell roster, full-game boss order, Weapon Upgrade Guide, Martyr's Tomb walkthrough, build tier list, map, quest walkthrough, multiplayer guide, or definitive price comparison is published. Magdalena tactics that lack cross-checked evidence (HP, official attack names, named phases) are also omitted.

## Migration decision

The existing public Guide URLs and static SEO architecture are preserved. The generic root landing and site chrome are made Mortal Shell II-specific so the root is not an unrelated indexable template page. No deployment or Vercel configuration change is made.
