## Spoiler warning

This page discusses the main ending, Baghead's secret ending, the core Baghead puzzle answer, and the Bag Holder trophy. Stop here if you want to discover those outcomes without guidance.

## Evidence boundary

This is a launch-window **Exploration Page**, not a complete lore archive. It covers the two ending routes currently supported by the research: the main ending and Baghead's secret ending.

The page intentionally avoids expanding unverified lore, treating every dialogue variation as a separate ending, or presenting unsupported ending branches. The useful distinction is route, puzzle condition, trophy outcome, and whether the main story remains available afterward.

## How many endings does Mortal Shell 2 have?

The current launch research supports two high-level outcomes:

1. **The main ending**, reached by continuing the central campaign route.
2. **Baghead's secret ending**, reached through the Baghead route in the Desolate Peak and Gloomshade Grove area.

This page does not claim that every dialogue difference creates a separate ending. It also does not expand the ending lore beyond what the current route evidence supports.

## Main ending

The main ending is the standard campaign conclusion. Finish [The Unfound Path](/mortal-shell-ii/unfound-path/) and defeat [Zmey, the Unbidden](/mortal-shell-ii/zmey/). Defeating Zmey is not the point of no return: current-cycle free roam and cleanup remain available. When ready, return to the **Gloom Siphon** in **Marrow Keep** and choose **Send Ova** to trigger the main ending and [New Game Plus](/mortal-shell-ii/new-game-plus/). **Send Ova is irreversible and is currently reported to have no confirmation prompt.**

Finish any optional weapons, Shell unlocks, Tarstone experiments, Beacons, or collectibles you want before committing. Use the [Map Fragments guide](/mortal-shell-ii/map-fragments/) for route visibility and the [Beacon locations guide](/mortal-shell-ii/beacons-fast-travel/) for travel infrastructure.

## Baghead secret ending

Baghead's secret ending is a separate route connected to **Desolate Peak** and **Gloomshade Grove**.

The route is easy to mishandle because the central puzzle answer is deliberately counterintuitive. The important instruction is to return with **“nothing.”**

### The “nothing” answer

When the Baghead route asks what to bring back, the correct result is **nothing**.

If you picked up **Special Moonshine**, put it back before completing the relevant Baghead interaction. Carrying the item forward is not the same as satisfying the “nothing” answer.

The safe sequence is:

1. Reach the Baghead route through the Desolate Peak / Gloomshade Grove area.
2. Follow the interaction until the return item question or requirement appears.
3. If Special Moonshine is in your possession, return it to its original place.
4. Complete the interaction with the “nothing” result.
5. Continue through the secret-ending sequence and confirm the trophy notification if it appears.

Do not substitute another item or assume that carrying Special Moonshine counts as returning with nothing.

### Bag Holder trophy

The **Bag Holder** trophy is associated with completing the Baghead secret-ending route.

Keep the trophy check separate from speculation about hidden lore or a complete list of ending variations. The current evidence supports the Baghead route, the “nothing” puzzle condition, and the trophy association; it does not justify adding unverified story explanations.

## Can you continue the main story after Baghead's ending?

Yes. Current research supports that completing the Baghead secret ending does not permanently block continued main-story play.

This makes the secret route a practical optional objective rather than a reason to abandon the save. If you want both endings in one playthrough, complete Baghead before using **Send Ova**. If you are still working toward the main ending, return to the normal progression route after the Baghead sequence and continue the campaign.

Before starting a new cycle, use the [New Game Plus guide](/mortal-shell-ii/new-game-plus/) to separate retained character progress from reset world state.

## Before pursuing an ending

Use this short preparation checklist:

- collect any weapon or Shell you want before the final route,
- finish the Beacon and map work that will make optional areas easier to revisit,
- complete Tarstone experiments if you want the current run's progression record,
- complete Baghead first if you want both endings in one playthrough, then finish cleanup before Send Ova,
- keep a save or backup point before the Baghead puzzle if your platform/build supports it,
- do not assume Night Mode changes the ending route unless current evidence explicitly says so.

The [Weapons Guide](/mortal-shell-ii/weapons/) and [Shells Guide](/mortal-shell-ii/shells/) can help with the optional preparation layer, but neither is a prerequisite for the ending route described here.

## FAQ

### What are the Mortal Shell 2 endings?

The current research supports the main campaign ending and Baghead's secret ending.

### Where is Baghead?

The secret route is associated with Desolate Peak and Gloomshade Grove. Use the surrounding Beacon and map context to reach the area.

### What should I bring back for Baghead?

Bring **nothing**. If you took Special Moonshine, put it back before completing the relevant interaction.

### What is the Bag Holder trophy?

Bag Holder is associated with completing Baghead's secret-ending route.

### Does Baghead's ending lock me out of the main story?

Current research supports continuing the main story afterward.

### Does Night Mode change the endings?

Do not assume it does. Current evidence does not support presenting Night Mode as a universal ending requirement.

### Does defeating Zmey end the game?

No. Defeating Zmey still leaves the current cycle available for exploration. The irreversible transition is selecting **Send Ova** at the Gloom Siphon in Marrow Keep, which advances the save into the ending / New Game Plus sequence.
