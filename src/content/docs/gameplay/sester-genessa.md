## Where is Sester Genessa?

Sester Genessa is located in **Marrow Keep**. The current unlock route treats the Keep as the meeting point: start by finding Genessa, then follow the interaction that points you toward Sester Secundus.

For the broader Shell system and the currently documented Shell routes, see the [Mortal Shell 2 Shells Guide](/mortal-shell-ii/shells/).

## How to unlock Genessa's Shell

Use this launch-safe route:

1. Reach **Marrow Keep** and locate Sester Genessa.
2. Follow the interaction or task direction that sends you to **Sester Secundus**.
3. Obtain the required task item from Sester Secundus.
4. Return to Genessa in Marrow Keep.
5. Complete the conversation or handoff interaction to unlock Genessa's Shell.

The important progression gate is the return to Genessa. If the Shell does not unlock immediately, finish the active dialogue and check the interaction prompt again rather than assuming that the route requires a different Shell or weapon.

## Is the item a Censer or a Chalice?

Current launch guides do not use one consistent name. Some call the item **Sester's Censer**, while others call it **Sester's Chalice**.

That naming difference is an evidence boundary, not a reason to invent two separate quest items. Use the item name and objective shown by your current game build, and follow the Sester Secundus → Genessa handoff. This page does not treat either English label as universally settled.
