## Launch status

**Devout Edition Advanced Access is live now.** Standard Edition unlocks **August 20, 2026 at 1:00 PM UTC** (9:00 PM Asia/Shanghai). These guides are built from current launch / Advanced Access gameplay and official developer posts, and they keep updating through the release window.

The Open Beta content on this site is kept only where it still answers real player questions — beta rewards, progress carry-over, and the Prologue skip. It is not presented as current full-game content.

## Confirmed game scope

**Mortal Shell II** is the standalone action-RPG sequel from Cold Symmetry and Playstack. The official descriptions reviewed for this site emphasize high-stakes combat, possessable warrior Shells, deeper weapon upgrades, an interconnected open world, and single-player play.

This hub separates confirmed release, gameplay, and PC requirement information into focused Guides. It does not turn preview language into an invented roster, build system, quest route, or map database.

## Evidence boundary

The reviewed official sources do not provide stable, complete evidence for a full Shell roster, full-game boss order, build tier list, map, quest walkthrough, multiplayer mode, or definitive price comparison. Those topics remain omitted. The earlier Open Beta Magdalena Guide is limited to the preview build; it will only be updated on the same URL if launch evidence supports it.
