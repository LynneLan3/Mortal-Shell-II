Use this page when something in Mortal Shell II is broken, stuck, or not behaving as expected. Each symptom cluster below links to the page that owns that intent — this hub does **not** replace those guides.

## PC crash, hotfix, stability

If the game crashes, freezes, or you need stability/hotfix information, open the dedicated crash page:

- [Crashing on PC — Hotfix 2.0 & fixes](/mortal-shell-ii/crashing-pc/)

This hub does not host crash hotfix details; use that page for crash-specific guidance.

## Beacon cleanse stuck / can't cleanse

1. Start at [Beacons and fast travel](/mortal-shell-ii/beacons-fast-travel/).
2. If the problem appears tied to the Citadel Annex cleanse, also open [Hushed Sanctum](/mortal-shell-ii/hushed-sanctum/).

## Isaac no damage / boss issue

For enemy or boss problems where attacks do no damage or mechanics appear broken:

- [Isaac, the Scholar Prince](/mortal-shell-ii/isaac-the-scholar-prince/)

## Hushed Sanctum stuck

For being blocked in or unable to finish the Citadel Annex cleanse:

- [Hushed Sanctum location & cleanse guide](/mortal-shell-ii/hushed-sanctum/)

## Save / progress / beta carry-over

1. [Beta progress carry-over](/mortal-shell-ii/beta-progress-carry-over/)
2. If the problem relates to starting or skipping early content: [Skip Prologue](/mortal-shell-ii/skip-prologue/)

## Shattering Stone chest open / missing

- [Tarstones database](/mortal-shell-ii/tarstones/) — includes a Week 1 bug note regarding Shattering Stone chests.

## Slayer Seal / achievement concerns

- [Slayer Seal difficulty](/mortal-shell-ii/slayer-seal-difficulty/)

## If you're not sure which applies

Scan the symptom list above and open the matching page. Each routed page contains the detailed troubleshooting or developer notes for that cluster.

## Common mistakes

- Searching this hub for crash hotfixes — crashes are routed to [Crashing on PC](/mortal-shell-ii/crashing-pc/) only.
- Using one page for both general Beacon cleansing and Hushed Sanctum issues — use the Beacons and Hushed Sanctum pages as noted.
- Assuming the Tarstones chest problem is permanent — check the [Tarstones](/mortal-shell-ii/tarstones/) page for the current bug note.
