## Minimum PC requirements

Steam currently publishes these minimum values for Mortal Shell II (English store listing):

| Requirement | Minimum listed value |
| --- | --- |
| Operating system | Windows 10 / 11 |
| Processor | Intel Core i7-10700K @ 3.8 GHz or better, or AMD Ryzen 5 3600 @ 3.6 GHz or better |
| Memory | 16 GB RAM |
| Graphics | NVIDIA GeForce RTX 2060 SUPER 8 GB, or AMD Radeon RX 6600 8 GB |
| DirectX | Version 12 |
| Storage | 70 GB available space |
| Drive | SSD required (Additional Notes) |

The listing was re-checked on 2026-08-20 against the current English Steam store page. Requirements can change after release, so verify the live Steam page before installing or upgrading a system.
